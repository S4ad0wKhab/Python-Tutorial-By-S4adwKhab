## python คืออะไร?
Python (ไพทอน) คือ ภาษาโปรแกรมมิ่งระดับสูง (High-level Programming Language) แบบ General-purpose ที่ใช้งานได้อเนกประสงค์

อ่านง่าย เขียนง่าย มีโครงสร้างและไวยากรณ์ (Syntax) ใกล้เคียงกับภาษาอังกฤษ เน้นการเว้นวรรค (Indentation) ทำให้โค้ดไม่ซับซ้อน เหมาะสำหรับผู้เริ่มต้น

มีชุดคำสั่งสำเร็จรูปมากมายที่ช่วยประหยัดเวลาในการพัฒนาโปรแกรม เช่น Pandas, NumPy, TensorFlow หรือ PyTorch
